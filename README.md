# 有符号距离场生成

纯 Python 标准库实现的 2D 有符号距离场（SDF）生成器，支持圆、矩形和（含凹陷的）
多边形，输出距离场灰度图与边界描边图，PNG 编码也由标准库 `struct`/`zlib` 手写完成。

## 符号约定（全图一致）

- **形状内部：负距离**
- **形状外部：正距离**
- **正好落在边界上：0**

## 实现方式

距离不是网格扫描出来的，而是对每个像素中心做**解析几何计算**：

- 圆：`到圆心距离 - 半径`，一步得到带符号距离；
- 矩形 / 多边形：取点到所有边界线段的欧氏最短距离，再按 `in_shape`
  的内外判定加符号。

因此：

- 距离是真实欧氏最短距离，保留浮点小数；斜向距离不被高估，
  圆的等距线仍是圆而不是八角形；
- 不依赖图像范围内的扫描传播，形状贴边甚至越出图像边界时，
  边界像素的距离依然准确，不会被截断。

## 各接口说明

| 接口 | 作用 |
| --- | --- |
| `in_shape(shape, x, y)` | 点是否在形状内；多边形用射线法，凹多边形的凹陷区正确判为外部 |
| `compute_sdf(shape, width, height)` | 返回浮点二维距离表，内负外正、边界为 0 |
| `normalize_sdf(dist, max_dist=8.0)` | 带符号线性映射到 0..255 灰度，保留内外差异；`max_dist` 即可配置的距离参考范围 |
| `outline(dist, width=2.0)` | 只保留 `|distance| <= width` 的边界环带；`width` 越大描边越厚 |
| `save_png_v(img, path)` | 灰度图存 RGBA PNG（标准库手写） |
| `Image(w, h, pixels=None)` | 一维像素数组的简单图像容器 |

### 可视化映射（内外不对称）

`normalize_sdf` 不再取绝对值，而是线性映射：

```
-max_dist（深内部） -> 0（黑）
0（边界）          -> 128（中灰）
+max_dist（远外部） -> 255（白）
```

内部偏暗、外部偏亮，看图即可分辨内外；超出参考范围的距离按端点截断。

### 描边（内部深处不入选）

`outline` 选取跨边界两侧、厚度各为 `width` 的环带（`|d| <= width`）。
内部深处 `|d|` 很大，不会被选中；宽度变化时描边像素数随之单调变化。

## 运行

```
python -m sdf.cli data/shapes.json --size 192 --out-dir out
python -m pytest tests -q
```

CLI 额外参数：

- `--max-dist`：归一化距离参考范围，默认 8 像素；
- `--outline-width`：描边环带半宽，默认 2 像素。

每个形状在输出目录生成两张图：`<name>_sdf.png`（距离场灰度图）和
`<name>_outline.png`（描边掩码，255 为描边像素）。

## 实测结果

命令：`python -m sdf.cli data/shapes.json --size 192 --out-dir out`
（默认 `--max-dist 8 --outline-width 2`）

| 形状 | 描边像素数 | 边界环距离最小值 | 边界环距离最大值 |
| --- | ---: | ---: | ---: |
| circle（半径 48 的圆） | 1224 | -0.9894 | 1.0000 |
| rect（100×70 矩形） | 1688 | -1.0000 | 1.0000 |
| poly（五边凹多边形） | 1982 | -0.9965 | 1.0000 |

“边界环”指与任一四邻域内外属性不同的像素（紧贴边界的内外两圈），
其距离绝对值不超过 1 个像素，符合像素中心采样的几何预期。

宽度可配置的验证（同一批形状，描边像素数随宽度单调增加）：

| 形状 | width=1 | width=2 | width=4 |
| --- | ---: | ---: | ---: |
| circle | 608 | 1224 | 2424 |
| rect | 1016 | 1688 | 3028 |
| poly | 1029 | 1982 | 3936 |

## 测试覆盖

`python -m pytest tests -q`（11 项全部通过）覆盖：

- 斜向距离等于真实欧氏距离、圆等距线无八角形偏差、距离保留小数；
- 三类形状全图符号一致（内负外正、边界为 0）；
- 归一化内外明暗不对称、参考范围可配置；
- 描边排除内部深处与远处外部、宽度变化像素数随之变化、零宽只剩边界；
- 凹多边形（U 形）凹陷区判为外部、自带五边形凹点判定；
- 形状贴边与越出图像边界时距离不被截断。
