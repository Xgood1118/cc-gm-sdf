在现有 sdf 骨架上，把它做成一个可用的有符号距离场生成器。保留 Image、in_shape、compute_sdf、
normalize_sdf、outline、save_png_v 的现有名字与签名，只用 Python 标准库，不得引入第三方依赖，
不得改动 data/shapes.json。

## 需要完成

1. **距离精度**
   - 距离要是到边界的真实最短距离，斜向不能偏高，圆的等距线不能是八角形。
   - 距离保留小数，不能只有整数级。

2. **符号**
   - 内部为负、外部为正（或相反，但要在 README 明确），全图符号一致。
   - 形状贴边时边界像素的距离仍要正确。

3. **可视化**
   - 归一化后能看出内外差异，不能是内外对称的图。
   - 距离参考范围可配置。

4. **描边**
   - 只取边界附近的等值线，内部深处不能被选中。
   - 描边宽度可配置，宽度变化时描边像素数随之变化。

5. **形状**
   - 圆、矩形、凹多边形三类都要正确，凹多边形的凹陷区不能判成内部。

6. **测试**
   - 覆盖：斜向距离不出八角形、符号一致、内部深处不入选描边、凹多边形判定、贴边不截断。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m sdf.cli data/shapes.json --size 192 --out-dir out`，把三个形状的描边像素数、
边界处距离的最大值与最小值贴进 README。
